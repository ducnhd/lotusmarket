🧰 Library features

  • 📡
    Fetchers
    VPS real-time · Entrade history · KBS fundamentals · Cafef insider · VCI dividends · Yahoo global · FRED macro — all free, no API key needed (FRED optional).
  • 📐
    Technical analysis
    RSI · MA20/50/200 · MACD · Bollinger Bands · ATR · momentum · weekly aggregation · signal + score 0-100.
  • ⭐
    Star ratings
    6-dim breakdown — price strength · trend · short-term · money flow · volatility · base range — deterministic, no AI.
  • 📊
    Market analysis
    Pulse score · regime classifier (STABLE/VOLATILE/CRISIS/EUPHORIA) · sector flow · driver attribution · risk indicators.
  • 🎯
    Signals
    Volume surge classifier · domestic flow (bid/ask pressure) · news clustering · earnings reaction.
  • 🔗
    Exposure chain
    Per-ticker external driver mapping with 2-year backtest-validated Pearson r — commodity / FX / peer correlations for 30+ VN30 tickers.
  • 🧪
    Backtest + cohort
    Strategy harness (buy-hold · momentum · low-vol · dual momentum) with realistic fees. Cohort analysis by RSI / MA trend / regime.
  • 🇻🇳
    Vietnamese NLP
    Sentiment (70+ financial keywords) · NLU intent parsing · ticker extraction · number parser.

🚀 Quick start

Python
# pip install
pip install lotusmarket==0.5.0

# Real-time quote + technical analysis
from lotusmarket.fetchers import vps_quote
from lotusmarket import technical, ratings

quote = vps_quote("ACB")
dash  = technical.dashboard(closes)
stars = ratings.compute(closes, vols, dash.score,
                        dash.rsi, dash.ma20, dash.ma50, dash.ma200)
print(stars.overall_verdict)  # Outperform
Go
// go get
go get github.com/ducnhd/lotusmarket/go@v0.5.0

// CLI binary
go install github.com/ducnhd/lotusmarket/go/cmd/lmcli@v0.5.0

lmcli pulse              # daily VN30 markdown
lmcli rate ACB           # 6-dim star ratings
lmcli screen --rsi=30-50 # filter VN30
lmcli dividends VNM      # corporate actions
lmcli global             # 14 world indices

⚙️ Cách trang này hoạt động

Trang này là 100% bot, zero-cost, zero server:

• GitHub Actions chạy lmcli mỗi ngày 15:30 VN (sau khi thị trường VN đóng cửa) — free trên public repo.
• Output được commit vào docs/, GitHub Pages serve miễn phí.
• Bot Telegram @vnlotusmarketbot post tóm tắt lên @vnlotusmarket.
• Code generate trang này nằm trong lmcli/html.go — bạn có thể fork và customize.

Tất cả dữ liệu lấy từ public API miễn phí (VPS, Entrade, Yahoo, VCI, Cafef). Không paid feed, không hot pick từ thầy, không vibe analysis — chỉ deterministic signal từ raw data.
